# Hackathon rule check

Checked against the official All Things Agentic Hackathon rules on 20 August 2026.

The official rules' Multiple Submissions section allows an entrant to submit more than one project, provided each entry is unique and substantially different from the entrant's other submissions.

Reality Diff satisfies that boundary: it is an end-user semantic memory and temporal photo-reasoning product for the Collaborative Partner track. AssuranceOS is an agent assurance/governance system. Their target user, problem, data model, interface, evidence, and demo flow are materially different.

The rules also require new work during the submission period and disclosure of pre-existing work. Reality Diff's implementation in this folder is new; the reusable engineering patterns are enumerated in `REUSE_DISCLOSURE.md`.

Official sources:

- <https://allthingsagentichackathon.devpost.com/rules>
- <https://allthingsagentichackathon.devpost.com/>

This is a project compliance note, not legal advice. Recheck the published rules immediately before submission in case Devpost posts an amendment.
