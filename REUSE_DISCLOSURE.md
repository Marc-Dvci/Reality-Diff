# Reuse disclosure

Reality Diff is a new and substantially distinct project for the All Things Agentic Hackathon's Collaborative Partner direction.

The entrant's other submission, AssuranceOS, is an agent assurance and governance product. Reality Diff instead serves an end user, reasons over photo history, models persistent physical subjects, and presents evidence-linked temporal answers. The applications do not share a domain model, fixture, user flow, model prompt, visual design, Android client, or deployed data.

General engineering patterns reused from the entrant's own prior work are limited to:

- a conventional `src/`, `tests/`, `docs/`, and `infrastructure/` repository layout;
- FastAPI health/readiness conventions;
- Docker non-root runtime and Terraform organization;
- evidence-oriented documentation and automated audit habits.

All Reality Diff product code, temporal fixtures, prompts, gallery integration, Google model pipeline, ADK tools, Android implementation, infrastructure names, visual design, and documentation in this folder were created for this project. Third-party Python, Java/Android, Google Cloud, Google model, and Pexels components remain governed by their own licenses and terms.
